# 🏗 Архитектура

## Высокоуровневая схема

```
┌──────────────┐    ┌──────────────┐    ┌──────────────┐
│ Telegram Bot │◄──►│  Backend API │◄──►│ TON / Wallet │
│   (юзер)     │    │   (Node/Py)  │    │ (escrow)     │
└──────────────┘    └──────┬───────┘    └──────────────┘
                          │
                          ▼
                   ┌──────────────┐
                   │  Price Feed  │
                   │ (CoinGecko) │
                   └──────────────┘

                          │
                          ▼
                   ┌──────────────┐
                   │ Payment Rail │
                   │  (СБП/карты) │
                   └──────────────┘
```

## Компоненты

### 1. Telegram Bot (`src/bot/`)
- Точка входа для пользователей
- Подключение TON-кошелька через TON Connect
- Оценка суммы, подтверждение сделки

### 2. Backend API (`src/api/`)
- REST API для бота и web-кабинета
- Расчёт курса с учётом ликвидности
- Управление ордерами и их статусами
- Аудит и логирование

### 3. Onchain (`src/onchain/`)
- Смарт-контракт escrow (удерживает ЦАРЬ до подтверждения выплаты)
- TON-кошелёк для приёма
- Multisig для крупных сумм

### 4. Payments
- СБП (через банк-партнёр или агрегатор)
- Прямой перевод на карту РФ
- Зарубежные карты — через партнёров

## Безопасность

- **Hot wallet** — отдельный адрес для приёма, лимиты на вывод
- **Cold storage** — основной резерв в холодном кошельке
- **Multisig** — для крупных операций
- **KYC/AML** — обязательно для сумм выше порога
- **Rate limiting** — защита от автоматических выводов

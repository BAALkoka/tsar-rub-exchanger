# payments/README.md

Платежные интеграции — варианты для выплат в рублях:

1) Полноценная автоматическая выплата на карту (эквайринг) — требует договора с банком/эквайером.
   - Поставщики: Tinkoff Acquiring, Сбербанк, CloudPayments, PayMaster и т.п.
   - Обычно требуют KYC и договор. API позволяет инициировать payout по номеру карты.

2) SBP (Система быстрых платежей) — чаще реализуется через эквайера/банкинг-провайдера.
   - Некоторые агрегаторы предлагают API для SBP payouts.

3) Binance P2P — чаще ручной: оператор продаёт RUB в P2P и помечает ордер как выполненный.
   - Автоматизация: официального публичного API для P2P нет — автоматизация рискованна и может привести к блокировке.

Рекомендуемый MVP-подход:
- На старте: ручные/полуавтоматические выплаты через админ-панель.
- После оформления договоров с эквайером — интегрировать API и перейти в автоматический режим.

Документы/действия для вас:
- Связаться с эквайером, получить тестовые/рабочие API-ключи
- Подписать договор и выяснить лимиты/комиссии
- Подготовить KYC-процессы
